# 出差报销助手 Travel Expense Assistant（MVP）

纯本地运行的 Web 工具：手机 / 电脑浏览器都能用，不需要服务器，数据全部保存在浏览器里。用于出差中快速记费用、传附件，出差后检查资料完整性并一键导出报销资料包。

## 打开方式

直接双击 `index.html`（用 Safari / Chrome / Edge 打开即可），不需要安装任何东西、不需要联网。

> 手机使用：把 `出差报销助手MVP` 文件夹传到手机，用手机浏览器打开 `index.html`，或加入主屏幕当作 App 用。

## 手机与电脑同步

数据默认保存在各自的浏览器里；要“自动保持同步”，需要在一台电脑上运行自带的轻量同步服务器（纯 Node 标准库，零依赖），手机和电脑连同一个 WiFi 即可：

```bash
cd 出差报销助手MVP
node server/sync-server.js
```

启动后终端会显示本机与手机访问地址，例如：

- 电脑：`http://localhost:8787`
- 手机：`http://192.168.1.108:8787`

然后在任意设备打开首页，在「☁️ 设备同步」卡片里填入服务器地址（如 `http://192.168.1.108:8787`），点「连接并同步」。之后任一设备改动数据，会在约 8 秒内自动同步到另一台设备；也可随时点「立即同步」。

说明：

- 同步采用**合并式策略**：按出差 / 费用 / 附件 id 做并集合并，两端数据都不会被覆盖丢失；同一笔数据的空字段用另一端补全；每次推送都会带上新时间戳
- 已知取舍：合并式同步不传播“删除”操作——在某台设备上删除的出差，可能被另一台设备同步回来；如需删除也能同步，需要后续加删除标记机制
- 附件（图片 / PDF）也会随数据一起同步
- 服务器只监听局域网，无账号鉴权，请勿把端口暴露到公网
- 不想用服务器时，仍可回到纯本地模式，或用「导出备份 / 导入备份」手动迁移
- 也可以通过 URL 参数自动连接：`http://电脑IP:8787/?syncServer=http://电脑IP:8787`

## 功能清单

### 出差管理
- 新建 / 编辑 / 删除出差：名称、地区类型（国内 / 海外）、开始 / 结束日期、多个行程城市
- 首页分「当前出差」与「历史出差」，卡片显示金额、附件数、资料完整度
- 首页「快速记一笔」直接按费用类型入口录入

### 费用管理
- 5 类费用：🍽 客情宴请、🍚 个人餐费、🏨 住宿费用、🚕 交通费用、📦 其他费用
- 各类型专属字段：
  - 客情宴请：餐厅名称、人数、客户名称
  - 个人餐费：餐厅名称
  - 住宿费用：酒店名称、入住 / 退房日期
  - 交通费用：出租车 / 个人滴滴 / 飞机 / 高铁，含起点终点、航班号、车站等
  - 其他费用：项目 / 说明
- 公共字段：日期、国家名称、城市、金额、币种、备注

### 附件管理
- 支持 jpg / png / heic 图片和 pdf，可在表单内按资料类型分槽上传
- 上传后自动按规则重命名：
  `费用类型-日期-地点-项目-金额-资料类型.扩展名`
  例：`客情宴请-2026-09-02-日本东京-XX餐厅-8500JPY-付款截图.png`
- 附件存于 IndexedDB，没有 5MB 限制

### 资料检查
- 根据费用类型、地区（国内 / 海外）、金额自动判断所需资料：
  - 客情宴请：国内 = 账单、发票、付款截图；海外 = 收据；海外超 1000 元加发票、支付记录
  - 个人餐费：国内 = 账单、发票；海外 = 收据；超 1000 元加发票、支付记录
  - 住宿费用：国内 = 酒店账单、发票；海外 = 收据
  - 交通费用：出租车 / 高铁 = 发票；滴滴 / 飞机 = 发票、行程单
- 展示每条费用 ✓ / ✗ 清单与整体完整度百分比

### 导出
- 生成报销资料包 ZIP：
  ```
  2026-09-日本客户拜访-报销资料包/
  ├── 报销明细.xlsx
  ├── 客情宴请/   个人餐费/   住宿费用/   交通费用/   其他费用/
  ```
- 报销明细.xlsx 字段：序号、费用类型、日期、国家、城市、项目、金额、币种、人民币金额、资料状态
- 单独导出报销明细.xlsx
- JSON 备份 / 导入（含附件，可换设备迁移）

### 报销状态流程
出差中 → 整理资料中 → 已生成报销包（提醒“请提交公司报销系统”）→ 已提交报销 / 审核中 → 已完成收款（弹窗询问是否删除附件）→ 已归档
- 完成收款时可一键删除全部附件（保留文字记录与金额统计）
- 状态也可在详情页手动切换

### 合理性校验
- 出差周期：结束日期不能早于开始日期；行程城市内每个城市的结束日期也不能早于开始日期
- 费用日期：必须落在出差周期的开始 / 结束日期之间（如 9/1–9/10 的出差不允许出现 10/1 的费用）
- 费用城市：必须在本次行程城市列表中（如只安排上海的出差，不允许填新疆的费用；多地出差则允许任一行程城市）
- 调整出差周期 / 城市时，如果已有费用超出新范围，会先提示确认

以上校验在填写时实时提示，保存时强制拦截；未设置行程城市或日期的旧数据不会强制校验。

## 人民币金额说明

导出表格里的「人民币金额」按汇率估算，默认汇率可在「导出」页的「汇率设置」中修改（仅本地保存）。CNY 汇率固定为 1。

## 数据存储说明

- 出差 / 费用 / 附件元信息：`localStorage`（key：`travelExpenseAssistantData_v1`）
- 附件文件：IndexedDB（库 `travelExpenseAssistant`，表 `files`）
- 同步设置：`localStorage`（key：`travelExpenseAssistantSync_v1`）
- 开启同步后，服务器数据保存在 `data/sync-state.json`（可用 `DATA_DIR` 环境变量改目录）
- 换设备 / 清缓存前，建议先用「导出备份」保存 JSON
- 本工具纯本地运行，数据不会上传到任何服务器

## 常见问题

- **HEIC 图片看不到预览**：浏览器不支持 HEIC 预览，但仍会正常保存、重命名并打进 ZIP。
- **导出文件打不开？**：ZIP 用系统解压工具或手机文件 App 解压；xlsx 用 Excel / WPS / Numbers 打开。
- **手机连不上同步服务器？**：确认手机和电脑在同一 WiFi；手机访问的是 `http://电脑IP:8787` 而不是 `localhost`；电脑防火墙若拦截请放行 Node。
- **两台设备同时编辑冲突怎么办？**：两端数据会按 id 合并，不会互相覆盖丢失；同一笔费用同一字段的编辑以后保存方为准。重要操作前仍建议先手动导出备份。
- **想重新开始**：清空浏览器站点数据，或先导出备份。
