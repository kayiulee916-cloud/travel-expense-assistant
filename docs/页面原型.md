# 页面原型

移动端优先，整体为单列卡片式布局，底部安全留白，最大宽度 600px。

> 移动端适配细节（来自最终合并方案）：
> - 断点 640px：以下走移动布局，以上走桌面布局
> - 录入弹窗为**底部面板**（圆角顶、保存按钮悬浮固定、适配刘海屏安全区）
> - 输入框字号 16px（避免 iOS 自动放大）、按钮触控区 ≥ 40px
> - 标签栏可横向滑动；出差卡片纵向堆叠；单列表单
> - 附件必传槽位红色高亮（`slot-miss`），另有「其他」补充槽
> - 桌面端为横向卡片布局 + 居中弹窗

## 6. 弹窗

- 新增 / 编辑出差：名称、地区类型、日期、多城市行（可增删）
